# Lune — Windows 音楽プレイヤー

Windows向けのローカル音楽プレイヤーです。[Releases](https://github.com/tuyoshi3509/Lune/releases) から `Lune-*-win-x64.zip` をダウンロードし、書き込み可能な場所にすべて展開して **`Lune.exe` をダブルクリック**すると起動します。GitHubの「Code → Download ZIP」はソースコードで、実行ファイルは含みません。

Windows x64と **.NET 10 Desktop Runtime（x64）** が必要です。アプリ本体と曲情報読み取りライブラリは `Lune.exe` にまとめています。`lune.portable` は実行ファイルと同じ場所に置いてください。`data` と `tools` は必要時に作成します。更新時は既存の `data`、`Music`、`tools` を保持してください。

.NET 10 Desktop Runtimeを利用するWPF製アプリです。音楽再生にブラウザーやサーバーは使いません。実行ファイルはコード署名していません。

起動済みの場合も同じ起動ファイルをダブルクリックすると、既存の通常画面を表示します。ミニ画面・最小化中からも復帰できます。画面外へ移動していたウィンドウはモニター内へ戻します。

標準では通常画面だけで起動します。ミニ画面は起動後に切り替えられます。「設定 → 次回からミニプレイヤーで起動」を明示的にオンにした場合のみ、次回からミニ画面だけを表示します。

通常画面・ミニ画面の「×」またはAlt+F4で、設定や再生記録を保存してアプリを完全終了します。取り込み中の外部プロセスも停止します。閉じた後に通知領域へ残す設定は廃止しました。設定や曲の詳細などの補助画面を閉じた場合は、その画面だけを閉じます。

## 曲を追加する

- エクスプローラーから曲・フォルダーを通常画面にドラッグ＆ドロップ。
- 「音楽を追加」からファイル、フォルダー、iTunes XML、M3U/M3U8を選択。
- 曲一覧から左側のマイリストへドラッグして登録。エクスプローラーから直接マイリストにドロップすることもできます。
- マイリスト内の曲をドラッグすると、ドロップ先の曲の直前に移動します。空白へドロップすると末尾へ移動します。複数選択、右クリックの「1つ上へ / 下へ」にも対応。
- 同一ファイルの重複登録は防ぎます。音楽は元の場所を参照し、移動やコピーは行いません。

新規起動時のライブラリは空です。「設定 → ライブラリパス」または「音楽を追加 → ライブラリパスを追加」で複数のフォルダーをまとめて選択・登録できます。既存ユーザーの登録済みパスは保持します。新しい曲を外部で追加した場合は「音楽を追加 → ライブラリを再スキャン」で更新できます。起動時は保存済みの曲情報を使うため、毎回全ファイルをスキャンしません。

曲を複数選択して右クリック →「ライブラリから削除…」で、対象を確認して「登録のみ解除」または「元ファイルも削除（ごみ箱へ）」を選べます。どちらもマイリストと再生キューから外します。登録のみ解除した曲は、ライブラリパス内にあれば再スキャンで戻ります。元ファイルを削除できなかった曲は登録を残します。再生記録は保持します。

## 再生と表示

- アルバム一覧、アーティスト → アルバム一覧、すべての曲、お気に入り、マイリスト、再生キュー。
- アルバム・アーティスト一覧の並び順メニュー右側の表示切り替えボタンで、サムネイル表示と小さな画像付きのリスト表示を選べます。表示方法はそれぞれ保存します。
- 一覧にページ送りはありません。アルバム・アーティストも最後までスクロールして参照できます。表示付近の行だけ描画するため、大きなライブラリでも画面を一度に作りません。
- アルバムをクリックして曲一覧を表示。曲をダブルクリック、または「すべて再生」で再生。
- 再生、一時停止、停止、前 / 次、シーク、音量、ミュート、シャッフル、全曲 / 1曲リピート。
- 曲を選んで再生した場合は、そのアルバムをディスク番号・曲番号の順で自動再生します。これは手動キューへ追加しません。「再生キューに追加」「次に再生」やキューへのドラッグで登録した曲を優先し、待っている曲がなくなると再生中の曲のアルバム順で次に進みます。「すべて再生」やマイリスト再生も、指定した一覧の再生順と手動キューを別々に保持します。旧版で自動作成された再生順は再生位置の復元に使用し、新しい手動キューへ自動追加しません。
- 再生中の長い曲名は通常画面・ミニ画面でゆっくり横スクロールします。曲一覧ではマウスを重ねた曲名をスクロールします。短い文字列や非表示の画面ではアニメーションを止めます。
- 「設定 → 再生・動作 → 再生操作の背景にイコライザを表示」で、音の周波数に連動する24本のバーを表示します。初期値はオフ。操作を妨げない薄い背景表示で、オンの場合も表示中・再生中だけ解析・描画します。音量調整前の音を使うため、ミュート中も曲に連動します。
- 「設定 → 音量の範囲」で最小・最大を0〜100％の間で指定できます。初期値は **0〜30％**。入力欄を離れるかEnterで適用し、通常画面・ミニ画面・キー操作に共通で反映します。現在の音量が範囲外なら範囲内へ調整し、次回起動時も保持します。ミュートは最小値によらず無音にします。
- 「設定 → 音声の出力先」、または通常画面の音量右側・ミニ画面上部のスピーカー型ボタンで**出力1・出力2**を選べます。出力2の初期値は**出力しない**。再生中でも曲・位置・音量を引き継いで切り替えられ、次回起動時も選択を保持します。
- 通常画面の音量下・ミニ画面上部の **1 / 2** ボタンで、その出力だけを1クリックでミュート・解除できます。音量スライダーは共通、スライダー横の音量アイコンは両方の一括ミュートです。各出力のミュートも保存します。同じ送信先を両方に指定した場合は音を重ねず、両方をミュートすると消音します。
- デバイス一覧では、再生デバイスの下に**録音デバイス**を表示します。通常のマイク端子に音を直接送り込むことはできません。VB-CABLEは対応するCABLE Input経由、VoicemeeterのB1 / B2 / B3はInput / AUX Input / VAIO3 Input経由で送信します。Voicemeeterを起動し、表示された入力列のB1 / B2 / B3をオンにして、録音・通話アプリの入力に対応するOut B1 / B2 / B3を選んでください。Luneはミキサーの設定を変更しません。対応する仮想入力がない項目は説明付きで選択不可にします。[Voicemeeterの入出力](https://voicemeeter.com/quick-tips-voicemeeter-virtual-inputs-and-outputs-windows-10-and-up/) / [VB-CABLE](https://vb-audio.com/Cable/)
- 「Windowsの既定のデバイス」はWindowsの出力先変更に追従します。出力1の再生デバイスが未接続なら既定の出力先を使います。出力2や仮想録音先が未接続なら、その出力を停止します。使える出力がなくなった場合は停止し、接続後に再生操作で再開できます。2系統の機器固有の遅延は異なることがあります。
- 曲の右クリックから「次に再生」「再生キューに追加」、マイリストへの追加、ファイルの場所の表示。
- 曲名 / アルバム名 / アーティスト名 / すべての項目で検索。複数語、英字の大文字小文字、日本語の全角・半角に対応。検索は表示中の一覧が対象で、「すべての曲」ではライブラリ全体を検索できます。
- 曲一覧の列見出しをクリックして並び替え。マイリストの保存順はドラッグまたは右クリックで変更します。
- 一覧上部の並び順メニューで、曲名・アルバム名の昇順／降順、追加順の昇順／降順を選択できます。曲・アルバム・アーティスト・マイリストの選択はそれぞれ保存します。マイリストは「マイリスト順」で保存済みの曲順に戻せます。並び替え表示だけではマイリストの保存順を変更しません。
- 新しい曲はLuneに追加した日時を記録します。既存の曲は初回だけファイルの作成日時を初期値とし、取得できなければ更新日時を使います。推定の日時は「詳細」に明示します。アルバムの追加日時は、収録曲で最も早い追加日時です。
- 曲に埋め込まれた画像、同じフォルダーの `cover.jpg` / `folder.jpg` / PNGなどをアルバムアートとして表示。同じアルバムの画像も共有します。
- アルバムの曲一覧の「アートを変更」で好きな画像を設定できます。この変更はLune内に保存します。
- 設定、マイリスト、お気に入り、再生キューと再生位置を保存。次回起動時は一時停止状態で復元します。

## プレイヤーのCD表示とアルバム画像

通常・ミニ画面の左側は、アートワークを丸く切り抜いたCD表示です。中央の穴と外周を付け、再生中は20秒で1回転します。一時停止・停止時はその角度で止まり、非表示・最小化中はアニメーションを取り除きます。回転は20fpsを上限とするWPFの変形のみで、画像の再読み込みや通信は行いません。

曲自身に画像がない場合、同じアルバム（アルバムアーティスト＋アルバム名）の画像を表示します。曲自身の画像があればそちらを優先します。アルバムにも画像がなければ既定のディスク画像になります。「アートを変更」で画像を追加できます。表示用の補完なので、音楽ファイルや曲に保存されている画像情報は変更しません。

補完は起動時・ライブラリ更新時にメモリ内で作り直し、未変更の再表示・画面移動・回転中の再検索は0回、補完によるファイル書き込みと外部通信は0回です。補完情報はライブラリ内の曲数に限定し、変更時に置き換え、曲削除・画像解除も次の更新で反映します。`--enhancements-test` で画像の優先順位、解除、保存データへの非混入、両画面の表示、停止・非表示・最小化時のアニメーション停止を確認します。

## シークとアルバムの右クリック

- 通常・ミニ画面のシークバーはクリック位置へ移動でき、ドラッグは離した位置で確定します。一時停止中は停止状態を保ちます。
- アルバムはカード表示・リスト表示のどちらでも右クリックできます。再生、次に再生、キュー・マイリストへの追加、お気に入り、詳細、削除を収録曲全体に適用します。再生順はディスク番号・曲番号を優先します。
- 「アルバムの詳細」では収録曲の累計再生時間と換算再生回数を確認できます。削除時は既存の確認画面で「登録のみ解除」「元ファイルも削除」を選べます。
- 曲・アルバムの「保存場所を開く」は実ファイルをエクスプローラーで選択します。アルバムが複数フォルダーに分かれる場合は保存先を選択でき、同じ保存先はまとめて表示します。ファイルがなくても親フォルダーが残っていればそこを開きます。
- メニュー表示・シーク操作に追加の外部通信やライブラリ読み込みはありません。シークはマウスを離した時だけ確定し、ドラッグ中に音声デバイスを繰り返し作り直しません。
- スクロールバーは表示件数が多くてもつまみの長さを28px以上に保ち、角丸が欠けないようにしています。アルバム一覧の仮想化は維持しています。

## マイリストを時間帯で再生する

マイリスト上部の時計ボタン、またはマイリストの右クリック →「時間帯で再生…」で設定します。初期状態はオフです。「このマイリストで時間帯再生を使う」をオンにし、開始時刻・終了時刻・曲を指定して保存してください。

- PCの現地時刻を使い、1時間単位で毎日繰り返します。例：6〜12時は朝のBGM、12〜22時は昼のBGM、22〜6時は夜のBGM。0〜24時で終日を指定できます。時間帯が重なる設定は保存できません。
- マイリストの「すべて再生」または右クリックの「再生」で、現在の時間帯の曲から開始します。曲を個別に指定した場合はその曲を優先し、次の時間帯から自動で切り替えます。
- 時間帯が変わると、曲の途中でもフェードアウトして次の曲を最初からフェードインします。標準はアウト5秒＋イン5秒で、各1〜30秒の選択肢から変更できます。音量スライダーや設定した音量範囲は変えず、2つの出力先にも同じフェードを適用します。
- 標準では、時間帯の曲が終わると同じ曲を繰り返します。「時間帯の曲が終わったら、その曲を繰り返す」をオフにすると、通常のマイリスト順（シャッフル・リピート設定を含む）で次へ進みます。時間帯のない時間も通常の順序で再生し、次の設定時間になれば自動で切り替えます。
- 一時停止・停止中に勝手に再生を始めることはありません。再開時に現在の時間帯を確認します。アプリ再起動後も一時停止状態で復元し、再開したときの時刻に合わせます。
- 別のアルバム・マイリストを再生した場合や、明示的な再生キューへ移った場合は、元の時間帯再生を解除します。時間帯の曲を再生キューへ自動追加することはありません。
- ミニ画面でも、曲選択から対象マイリストを選ぶと「時計の時間帯に合わせて再生」を使えます。

時刻の確認は時間帯再生中だけ1秒間隔で行い、フェードの更新も切り替え中だけ動作します。PCのスリープ中は動作せず、復帰後に現在の時間帯を確認します。

## 曲ごとの再生記録

曲を右クリックして「詳細」を開くと、**累計再生時間**と**換算再生回数**を確認できます。換算再生回数は「累計再生時間 ÷ 曲の長さ」です。例えば、曲の半分を2回聴くと1.00回になります。曲の長さが不明な場合は回数を「—」で表示します。

Windowsの出力ストリームが再生した時間を加算し、一時停止中やシークで飛ばした時間は除外します。リピートや巻き戻して聴き直した部分は加算します。ミュート中も再生が進んでいれば加算します。通常画面・ミニ画面・最小化中で共通の記録です。2つの出力先で同時再生しても、再生時間は二重加算しません。

記録はこの機能の追加後から始まります。過去のLuneやiTunesでの再生履歴は含みません。履歴は `data\playback-history.json` に曲のIDごとに保存し、再起動やメタデータの再スキャン後も引き継ぎます。15秒ごと、および一時停止・停止・曲の切り替え・終了時などに保存します。ファイルの移動によってパスが変わると別の曲として扱います。

アーティスト一覧を右クリック →「アーティストの詳細」、またはアーティストを開いた画面の「••• → アーティストの詳細」から、アーティスト全体の累計再生時間・換算再生回数と曲ごとの内訳を確認できます。換算回数は各曲の「累計再生時間 ÷ 曲の長さ」の合計です。現在ライブラリに登録されている曲を集計し、長さが不明な曲の再生時間は合計に含め、回数の計算からは除外します。

## ミニプレイヤー

右上または右下の斜め矢印ボタン、あるいは `Ctrl+M` で、428 × 200 の小さなプレイヤーに切り替えます。

アルバムアート、曲名、前後の曲、再生 / 一時停止、停止、シャッフル、リピート、シーク、音量、お気に入りを操作できます。右下の一覧ボタンから曲検索やマイリスト選択もできます。上端をドラッグして移動、ピンで最前面表示を切り替えます。

「設定」で外観20種類（暗色15種類・明色5種類）、アクセントカラー、30〜100%の不透明度、ミニ画面での起動、メディアキーの使用を変更できます。テーマを選ぶと対応する背景・文字・アクセントの配色を適用します。アクセントはさらに個別に調整できます。一般的なウィンドウとして表示するため、ゲームの排他的フルスクリーンの上には表示されない場合があります。必要ならゲーム側をボーダーレス表示にしてください。

## Discordに再生中の曲を表示する

「設定 → Discord連携」に、Application IDの作成手順とDiscord Developer Portalを開くボタンがあります。初期状態はオフです。

1. 作成ページで「New Application」から「Lune」を作成します。
2. 「General Information」の「APPLICATION ID」をコピーし、Luneの設定欄に貼り付けて保存します。Client Secret・ユーザートークン・Botの作成は不要です。
3. 「Discordに再生中の曲を表示する」をオンにし、Discordデスクトップ版を起動します。
4. Discordの「ユーザー設定 → アクティビティのプライバシー」でアクティビティの共有をオンにします。

再生中のアーティストを「♪ アーティスト名」、詳細に曲名と再生時間を送信します。表示はDiscordの共有設定に従って他の人にも見えます。一時停止・停止・連携オフ・Luneの終了時は解除し、再開時や曲の変更、シークに追従します。曲情報の更新は通常5秒以内を目安にまとめ、Discordの起動待ち・切断時は15秒間隔で再接続します。オフ時は接続・再試行しません。

通信はPC内のDiscord連携用IPCを使い、別の常駐プロセスは追加しません。曲名・アーティスト・再生時間以外に、音楽ファイルのパス、元動画のURL、PC内のアルバムアートを送信しません。Discordのブラウザー版だけでは利用できません。Spotify専用の「一緒に聴く」は付かず、表示位置や見た目はDiscord側の仕様に依存します。

仕様は [Discord公式のRich Presenceガイド](https://docs.discord.com/developers/discord-social-sdk/development-guides/setting-rich-presence) と [RPC仕様](https://docs.discord.com/developers/topics/rpc) を参照しています。実際のアカウントでの表示は、ご自身のApplication IDを設定した後に確認してください。

## iTunes

iTunes Media 内の実ファイルを直接読み込みます。独自形式の `.itl` を解析する方式ではありません。

iTunesのマイリストを移す場合は、iTunesでライブラリをXMLに書き出し、Luneの「音楽を追加 → iTunes XML / M3Uを読み込む」から指定します。XMLのファイルをドラッグしても取り込めます。ファイルの場所が現在も有効な曲と、通常のマイリストの曲順を取り込みます。同じXMLの再取り込みでは対応するマイリストを更新します。スマートプレイリストの条件の自動実行、クラウド上だけにある曲、iTunes独自のアートキャッシュ `.itc2` の直接解析は対象外です。

保護付き `.m4p` は再生対象外です。ローカルのMP3・M4A・FLAC・WAVをこのPCで確認済みです。AAC・WMA・AIFF・OGG・OPUS等はWindowsに導入されているコーデックに依存します。

読み取りに問題があるファイルは曲名に `⚠` を表示します。連続再生では読み取り注意の曲をスキップし、指定した曲は個別に再生を試せます。「設定 → 読み取り注意の一覧を開く」、または `data\read-issues.tsv` で対象を確認できます。アプリによる元ファイルの修復・書き換えは行いません。

## YouTube URLから音声を取り込む

ライブラリの「YouTube」では取り込んだ曲だけを表示します。同じ曲は通常の曲・アルバム・アーティスト一覧にも表示されます。曲一覧の「動画」列のボタンから元動画を開けます。過去にアプリの標準取り込みフォルダーへ追加した曲も分類しますが、記録開始前で元URLが不明な曲のボタンは無効表示になります。

1. 「URLから取り込む」を開いて動画URLを入力。
2. 「動画の情報を取得」を押して曲名、投稿者等、提供されていればアーティストとアルバム、サムネイルを取得。画像を取得すると正方形の切り抜き画面が開きます。
3. 曲名・アーティスト・アルバムを必要に応じて編集。「画像を選ぶ」で独自のアートも指定可能。
4. M4AまたはMP3を選び、「保存してライブラリに追加」。

ライブラリへの登録が完了すると、取り込み画面は自動で閉じます。完了メッセージは通常画面に表示します。失敗・中断した場合は取り込み画面を残します。

アルバム欄の右端の矢印から、同じアーティストの登録済みアルバムを選べます。YouTube由来の曲に加え、ローカル曲・アルバムアーティストが一致する曲も候補に含みます。アーティスト名の編集に合わせて候補が更新され、アルバム名の手入力はそのまま残ります。候補にない名前も直接入力できます。

アーティスト欄も候補選択と手入力に対応します。以前YouTubeから取り込んだ曲に登録されている名前を候補に表示します。今後の取り込みでは取得元の名前と保存時の名前を `data\import-artists.json` に記録し、同じ取得元で使った名前を優先して表示します。候補の表示だけで入力内容を変更することはありません。

### 再生リストをまとめて取り込む

「URLから取り込む → 再生リストからまとめて取り込む…」でYouTubeの再生リストURLを指定し、「再生リストの曲を取得」を押します。通常のURL欄に動画を指定しない再生リストURLを入力した場合も、この画面へ進みます。動画URLに `list=…` が付いている場合は、まとめ取り込みボタンでリスト全体を指定できます。

- 一覧のチェックで取り込む曲を選びます。動画の並び順を保持し、ページ送りなしでスクロールできます。
- 曲を選ぶと下の欄で曲名・アーティスト・アルバムを編集できます。アーティストとアルバムは、チェックした曲へまとめて反映することもできます。後から詳細情報を取得しても、編集済みの名前は保持します。
- アートは各動画から自動取得して中央を正方形に切り抜きます。事前に曲を選び「画像・詳細を取得 → 切り抜き位置を調整」で位置を変更したり、「画像を選ぶ」で指定できます。
- 登録済みの動画は初期状態で除外します。同じ動画かどうかは保存済みの元動画URLで判定します。URLが記録されていない古い曲は判定できません。再度取り込む場合は「登録済みの動画は取り込まない」をオフにして選択します。
- 「Luneにもマイリストを作成」をオンにすると、保存した曲とすでに登録済みの曲から、元の順番を保ったマイリストを作ります。同じYouTube再生リストの再取り込みでは同じマイリストを更新します。
- 1曲ずつ取り込み、失敗した曲があっても次に進みます。中止しても保存済みの曲を残し、同じ画面から失敗・未処理の曲を再試行できます。アプリを終了した場合は再生リストを再取得すると、登録済みの曲を除外できます。
- 選択した曲の取り込みとマイリスト登録が正常に完了すると、まとめ取り込み画面と元のURL取り込み画面を閉じます。一部失敗・中断した場合は再試行できるよう画面を残します。
- 非公開・削除済み・配信中・配信予定などの動画は対象外です。ログインやCookieの読み込みは行いません。

切り抜き画面では、元画像全体の上にある正方形をドラッグして位置を調整します。枠の外のクリックでも移動でき、スライダーまたはホイールで拡大・縮小、矢印キーで微調整（Shift併用で10ピクセル）できます。「仕上がり」で確認し、「この範囲で切り抜く」で確定します。取り込み画面の「切り抜き位置を調整…」から何度でも元画像を使ってやり直せます。キャンセルは直前に確定した範囲を保ち、初回は中央の正方形を使います。手動で選ぶ画像も同じように調整できます。確定した正方形の画像を、M4A/MP3のアルバムアートとして保存します。

新しく取り込む曲には元動画のURLも保存します。曲を右クリック →「詳細」の「元動画のURL」から確認・コピー・元動画の表示ができます。URLはライブラリと音楽ファイルのコメント欄（`Lune source URL:`）に保持し、ファイルを読み込み直しても復元できます。この機能の追加前に取り込んだ曲のURLは自動では補完しません。

初期保存先はプロジェクトの `Music\Imports` です。設定で変更できます。音楽ファイルに日本語の曲情報と画像を埋め込み、同名ファイルがある場合は連番を付けます。動画タイトルから正確な楽曲情報を特定できない場合は、保存前に手入力してください。

取り込みに使う yt-dlp・FFmpeg・Deno は配布ZIPに含みません。初回利用時にネット接続してダウンロードしSHA256を確認します。`tools` フォルダーに保存し、再生中には常駐しません。「取り込み機能を更新」でyt-dlpを更新できます。プロセスは通常より低い優先度で動き、途中キャンセルに対応します。

保存・利用する権利がある動画に使用してください。非公開・ログイン必須・保護付き・提供終了・地域制限等の動画には対応していません。外部サイトの仕様変更などで取得できない場合もあります。アカウントのCookieの取り込みや保護解除は実装していません。

## データ・軽量動作

- `data`：ライブラリ、マイリスト、設定、縮小画像。JSONは一時ファイルから置換して保存し、直前の `.bak` を保持します。
- `Music\Imports`：URLから取り込んだ音楽。
- `tools`：取り込み時だけ起動する外部ツール。合計約306MiBのディスク領域を使います。
- `Lune.exe`：ダブルクリックで起動する実行ファイル。アプリ本体を1つにまとめ、インストール済みのランタイムを使用します。
- `release`：ビルド時の出力先。`build.ps1` はここからフォルダー直下にも `Lune.exe` を配置します。
- `test-output`：検証ログ・スクリーンショット・テスト用生成物。通常のライブラリには登録しません。

バックアップは `data` と `Music\Imports` をコピーしてください。別の場所に移す場合はこのプロジェクトのフォルダー一式を移し、元の音楽ファイルのパスも維持してください。この版の設定・キャッシュには絶対パスを含みます。

音声はWindowsのMedia FoundationとWASAPI共有モードを使います。出力先の指定はLune内に適用し、Windows全体の既定デバイスは変更しません。曲一覧とアルバムの行を仮想化し、画像を縮小、検索を短く待ってから実行します。再生中の位置更新は0.5秒ごと、最小化時は2秒ごと、停止時はタイマーを止めます。デバイスの接続変更はWindowsの通知で検知します。ミニ画面では通常画面の一覧表示を解放します。実測結果は `test-output\performance.txt` に記録しています。ゲーム自体のFPS比較や全コーデックの検証は実施していません。

## アプリの更新（v1.1.0以降）

左下の「アップデート」または設定のバージョンボタンから確認できます。起動時は最大1日1回、GitHubの正式版Releaseを確認します。自動確認は更新画面でオフにできます。手動の「今すぐ確認」もあります。

更新が見つかったら「更新して再起動」を押してください。SHA256・ZIP内のファイル・実行ファイルのバージョンを検証した後、再生を終了して更新します。音楽・ライブラリ・マイリスト・設定・外部ツールは上書きしません。更新後の起動を確認できなかった場合は旧版への復元を試み、結果を `data/updates` に記録します。書き込み可能な実体フォルダーで使用してください。

更新通知は画面内のボタンと通知領域に表示します。Windows側の通知設定によって通知領域の表示は抑止されることがあります。更新情報のキャッシュは1件、同時確認は1要求に統合し、ETagで未変更の場合は本文を転送しません。成功済みの更新記録は最大8件、未完了の準備は最大3件とし、失敗時のバックアップは自動削除しません。

v1.0.0にはアプリ内更新機能がないため、最初の1回だけReleasesから更新対応版をダウンロードして入れ替えてください。
